  1. Download the archive with the button above.

Если Windows покажет окно «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». Так бывает со всеми играми от небольших разработчиков без платной цифровой подписи. If Windows shows "Windows protected your PC", click "More info" → "Run anyway". This happens with most games from small developers without a paid code signature.

На ретро-консоли (PortMaster)On a retro handheld (PortMaster)

  1. На консоли должен быть установлен PortMaster.
  2. Распакуй архив и скопируй Balcony Garden.sh и папку balconygarden в папку ports на карте памяти.
  3. Если у консоли нет интернета, скачай рантаймы godot_4.3 и weston_pkg_0.2 с сайта PortMaster и положи их в PortMaster/libs.
  4. Запусти игру из раздела Ports. Всё на кнопках: A — полить, X — аптека, Y — книга, Start — меню, L1/R1 — горшки, B — закрыть окно.
  1. PortMaster must be installed on the handheld.
  2. Unzip the archive and copy Balcony Garden.sh and the balconygarden folder into ports on the SD card.
  3. If the handheld has no internet, download the godot_4.3 and weston_pkg_0.2 runtimes from the PortMaster site into PortMaster/libs.
  4. Start the game from Ports. Fully on buttons: A — water, X — remedies, Y — book, Start — menu, L1/R1 — pots, B — close.
